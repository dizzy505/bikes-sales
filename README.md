🚀 Project Overview
---------------------
This project analyzes a bike sales dataset through Excel dan Tableau, following Alex The Analyst’s guide with additional deeper segmentation and predictive scoring system to estimate potential buyers.

🛠️ Tech Stack
- Microsoft Excel
- Tableau Public
- PivotTables
- PivotCharts
- Manual Rule-Based Prediction

📋 How to Run
- Open bike_sales.xlsx or
- Open this link:
```bash
https://public.tableau.com/views/BikeSalesDashboard_17460906746870/Dashboard1?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link
```
- Explore the sheets: Data Preparation, Pivot Analysis, Manual Prediction, Dashboard

✨ Key Insights
- Identified customer demographics most likely to purchase bikes.
- Found peak sales months and high-performing regions.
- Built a simple scoring model to predict purchase likelihood.
